# 归屿 v0.3：查找、条件统计、多轮追问与本地模型库

2026 年 10 月 21 日更新。v0.3 在既有办公工具与保存点之上，增加了可复核的资料查找、行筛选、分组统计和同一资料范围内的连续追问。应用仍在本机读取和推理，不连接在线模型。

## 三分钟体验

打开归屿，点击“体验条件统计与连续追问”，按 `⌘ ↵`，查看条件后执行。内置 CSV 是虚构台账，六笔费用共 709.00 元。

1. “只统计状态包含待报销且金额大于100元，按经办人分组统计。”匹配两笔：林晓 128.50 元、陈雨 180.00 元。
2. 继续问“那陈雨呢？”沿用待报销、金额大于100元和分组要求，增加经办人条件，得到 180.00 元。
3. 问“那林晓呢？”替换经办人条件，得到 128.50 元。
4. 问“清除筛选，取消分组，统计全部记录。”恢复六笔费用，总额 709.00 元。
5. 点击“写成简短说明”，使用本轮有效数据和统计结果生成文稿。

也可点击输入框旁的筛选图标，选择字段、比较方式、值、条件关系、分组和统计字段，再查看计划。已有值可从菜单选择。筛选结果与统计结果分别导出，统计工作簿附参与计算的数据和原始数据行号。

## 查找如何工作

“查找‘交通’相关资料”在已授权文件的本地文本与文件名中做字面匹配，返回匹配摘录、来源编号与行号。多个以空格分隔的词须全部出现；结果按出现次数和文件名匹配排序。不会把没有匹配的文件补成结果。

查找、提取与统计组合成任务时，后续工具只使用匹配文件。无匹配时会展示空结果，后续读取工具会停止，要求重新规划。结果卡片可查看原文，或以匹配文件建立新的资料范围。

当前不是语义向量检索，不会把“报销”和任意近义表达自动视为相同。文本读取每文件最多60,000个字符，长资料会提示检索覆盖范围；PDF 需要文字层，扫描件仍需后续 OCR。CSV 查找以文件为单位匹配，行级选择由筛选工具完成。

## 条件与计算

支持等于、不等于、包含、不包含、大于、不少于、小于、不超过；条件可全部满足或任一满足。数值使用 Decimal，日期比较接受明确的 `YYYY-MM-DD`。大小比较不会执行公式或代码，也不会把非数值按字符串大小排列。单位不一致时停止并要求明确单位。

自然语言覆盖明确字段条件、表内已有姓名与状态、按字段分组等常见表达。不能确定的条件会返回可操作提示，并保留上一轮结果，便于改写。相对日期、排名及混合嵌套的“且/或”暂需改为明确条件。包含比较采用字面子串，例如“未付款”也包含“付款”，需要区分时应选择等于。

最多1,000行、40列；Excel使用首个工作表和已有公式缓存值，不运行公式。多文件须相同表头。筛选零行就显示零行，不用全表替代。按组生成合计、均值、极值和有效数值数；面板可指定一个数值字段，默认全部可统计数值列。

## 多轮状态

每轮以父任务编号连接，保留同一线程、原始表格、条件、分组和资料哈希。换姓名会替换同字段条件，其他条件保留。清除筛选重新使用保留的原始表格。查找曾缩小文件范围时，明确恢复全部记录会回到原授权范围并按需重新提取。

资料或文件范围变化会要求重新规划，不能直接拿旧表推断新资料。原始表格来自模型提取时，字段仍须核对原文；复用表格不使其自动变为人工确认的数据。普通生成任务近期最多六轮对话进入模型上下文；存在行筛选时，写作与问答只接收当前匹配行、当前计算结果及出处，旧轮次和已排除行不进入事实上下文。结构化条件与原始表格独立保存。界面折叠展示此前轮次，点历史可以回到对应分支继续。

## 自己选择本地模型

点击顶部模型名称进入模型库，选择“添加本地模型文件夹”。选择已准备好的 MLX 模型目录，包含 `config.json`、`tokenizer_config.json` 和 safetensors 权重。支持单文件与分片权重，由已安装 MLX LM 的内置架构决定具体兼容性；当前不支持 GGUF / Ollama 格式。

权重保留在原目录，不复制到工作记录。模型选择与目录保存在本机，重启后沿用。切换会终止旧 worker、加载选定模型并重新运行网络拒绝探针，完成后才允许任务。已完成的对话可以继续；尚未执行或未完成的计划要用新模型重新规划，以免混用步骤。模型无法加载时可在模型库切回已有模型。

默认 Qwen3 4B 仍可直接使用。其他模型先准备到本机，再添加；应用本身没有在线 API 或云端回退。可选的 `scripts/prepare_local_model.py` 接受仓库、固定40位提交与独立新目录，下载阶段不读取任务资料，且不加载仓库自定义代码：

```sh
"$HOME/Library/Application Support/GuiyuRuntime/python/bin/python" scripts/prepare_local_model.py \
  --repository OWNER/MODEL --revision COMMIT_SHA_40_HEX --destination /path/to/new-model
```

这里的仓库、提交和目录需换为实际选择。准备脚本需联网，资料处理仍禁网。模型来源、体积、许可和中文质量应按实际选择核对。当前实测质量与性能数据来自默认 Qwen3，不能外推到其他模型。

## 验证与复用

`backend/local_query.py` 实现字面查找和受约束的行查询，`backend/model_info.py` 在加载前检查本地模型；执行器保留范围及哈希校验。新界面在 `QueryViews.swift` 与 `QueryModels.swift`。虚构台账在 `fixtures/query`。

48项单元测试通过，覆盖旧文件防护以及查询、状态继承、清除条件、分组、单位、零匹配和模型切换限制。18项实际模型查询检查通过，报告见 `qa/v0.3-query-integration-report.json`。GUI 与模型切换记录见 `qa/v0.3-gui-report.json`。这些是开发验证，尚无真实用户完成率或跨模型质量对比。

# v0.5：工作区自动检索与资料更新

选择文件夹作为工作区后，归屿默认使用“自动找资料”。用户直接提出问题，归屿从整个已授权工作区检索相关文档，展示出处与片段，再安排查找、提取、统计、写作和追问。需要固定资料时，可切到“手动选择”。

## 在界面中使用

1. 左侧工作区卡片 → 选择文件夹。首次会读取支持格式并建立本地索引。
2. “我的资料”显示索引状态、资料与片段数量、最近检查时间和未读取原因。默认无需逐份勾选。
3. 直接问“查找差旅支出”“只统计状态包含待报销且金额大于100元，按经办人分组统计，再写一份说明”。
4. 展开“已从工作区找到相关资料”核对选取范围、片段、行号与匹配依据。确认计划后执行。
5. 可继续问“那陈雨呢？”或“把本轮结果写成说明”。文件变化后，新一轮重新检索并计算，保留可解析的筛选条件。

模型库新增“BGE 中文语义检索”，约 96.4 MB，下载后供工作区自动使用，与对话模型分别管理。它不是对话模型，无需切换当前 Qwen。尚未准备时界面明确显示关键词模式，并提供准备入口；没有云端向量服务回退。

“清空索引并暂停”删除本地索引内容并暂停自动更新，原文档和历史工作记录保留。点击“建立索引”恢复。清空工作记录与清空索引是两个独立操作。

## 本地实现

- 使用 [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)，MIT，固定提交 `7999e1d3359715c523056ef9478215996d62a620`。文件清单、尺寸与 SHA256 在 `packaging/model-catalog.json`，下载器逐文件校验，编码器启动时再次校验。
- 以现有 MLX 与 tokenizers 实现 BERT 编码，CLS 池化及 L2 归一化，512 维。v1.5 使用无指令前缀的短中文查询，不导入模型仓库代码，不需要 PyTorch 或在线 API。
- 默认按 320 字符切片、重叠 48 字符，保留原始文件、字符位置、行号和内容哈希。检索结合本地向量相似度与关键词，生成时优先使用通过原文校验的命中片段。
- SQLite 索引位于该工作区自己的本机数据目录，与其他工作区分开。文件内容、向量、问题和检索结果仅通过本地匿名管道处理。
- 独立的索引进程继承主应用禁网策略，启动后自行探测，隔离失败时停止。BGE 下载继续使用独立下载组件；模型准备不接收文档或查询内容。
- macOS FSEvents 监听创建、修改、删除和改名，进行短暂防抖；另每 30 秒检查一次。每次查询前也检查文件状态。未变文件复用向量，变化文件替换索引，删除和改名清除旧路径。
- 隐藏文件、符号链接、应用包和归屿自己的数据/模型目录不进入内容索引。任务开始、每步开始及结束时核对资料哈希，变化时停止发布新步骤结果。

## 追问与统计范围

同一线程且工作区未变化时，继续沿用资料范围、原始表格和条件。工作区版本变化时重新检索，重新读取原始数据，重用查询意图；不复用过期表格或旧工具结果，旧助手数字不会作为本轮事实依据。历史结果仍可回看。

检索是相关性排序，界面明确展示本次实际使用的文档；默认统计仅覆盖检索到并纳入任务的资料。要求整个工作区的全量任务时，必须满足完整读取与单次任务范围，超限会停止并说明。

工作区可索引最多 2,000 份文档、遍历 20,000 个文件项、存储 50,000 个片段。单文件 8 MiB，每份提取最多 60,000 字符。Excel 内容检索每表读取最多 1,000 行。达到边界或读取失败会显示原因。

单次工具计划仍最多使用 40 份文档。一般问答/写作默认取至多 8 份相关资料；自动统计纳入全部匹配候选，超过 40 份时要求缩小范围，不静默截取后给出总数。自动统计遇到未完整读取的资料、过长文本、多工作表 Excel、混合表格和文本时会要求明确范围。表格统计沿用 1,000 行、40 列及一致表头要求。扫描件 OCR 不在本轮范围内。

## 隐私与验证

索引包含文本片段和向量，是私密资料的本机副本；当前未做应用级加密。系统备份和同步目录遵循系统设置。清空索引使用 SQLite secure_delete 并收缩数据库，但不承诺擦除系统快照或备份。网络策略仍使用当前 Demo 的 Seatbelt API，尚无独立安全审计或形式化证明。

`python scripts/check_workspace.py` 在禁网子进程中使用真实 BGE 与真实 Qwen，验证近义匹配、48/46 份文档自动选取、统计写作、条件追问、金额由 180 变为 280 后重新计算、改名删除和缓存复用。原生文件事件实测与 GUI 报告位于 `qa/v0.5-*.json`。这些是虚构资料上的功能检查，尚无真实用户完成率或系统性检索召回率结论。

开发者可用 `scripts/prepare_embedding.py` 做固定模型的独立准备与校验；普通用户使用模型库。模型权重与私密索引不进入源码或 Demo 分发包。

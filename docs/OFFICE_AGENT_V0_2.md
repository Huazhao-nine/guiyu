# 归屿 v0.2：本地办公 Agent

版本 0.2.0，2026 年 10 月 21 日。优先服务资料与日常办公：查找、提取、统计、写作与整理。核心体验是用中文交代目标、查看计划、执行本地工具、核对成果。

## 快速体验

在已准备好的 M5 32 GB 上打开归屿，点击“体验一次多步办公”，按 `⌘ ↵`，查看四步计划后开始。示例使用三份虚构费用资料：128.50、260.00、43.20 元，合计 431.70 元，平均值 143.90 元。

![四步计划](../qa/guiyu-v0.2-plan.png)

可以编辑每一步的要求、关闭不需要的步骤。开始后逐步显示状态、耗时与结果。停止任务会保留完成结果，重启后可继续剩余步骤；被中断的那一步从头执行。

## 工具与结果

| 工具 | 行为 | 文件影响 |
| --- | --- | --- |
| 查找 | 对已选资料做关键词排序，展示最多八份原文片段 | 只读 |
| 提取 | 本地模型按要求提取字段、保留来源与核对提示 | 新建 XLSX |
| 统计 | 对前序表格或 CSV / Excel 用 Decimal 计算合计、均值、最小值与最大值 | 新建 XLSX，附参与统计的数据 |
| 汇总 | 沿用原文片段选择和来源核对 | 新建 DOCX |
| 写作 | 根据用户要求、资料和前序结果起草、改写或翻译 | 新建 DOCX 与 Markdown |
| 问答 | 根据资料、近期对话和前序结果回答 | 保存本机记录 |
| 整理 | 拟定内容分类和中文命名 | 仅预览；另行确认后改名，可撤销 |

常见办公意图用规则编译为固定工具序列，未识别时由本地模型选择已注册工具。一次最多六步，执行前可见。统计依赖提取表格或原始结构化文件，关闭必要前置步骤会被拒绝。整理预览置于最后。

## 保存与续跑

规划时固定文件范围和 SHA256。开始及每一步前校验范围与内容，发现变动就要求重新规划。`Plans/<任务ID>.json` 保存步骤、结果和尝试次数；应用另存 `pending-plan.json` 以恢复当前界面。完成的步骤复用原结果，未完成步骤每次尝试使用新的输出目录，每步最多尝试三次。停止任务会终止当前 worker，再启动新的隔离 worker。

每个成果保留自己的预览内容。提取表展示原始记录，统计表展示统计字段，不因多个 XLSX 共处一个任务而混用预览。既有 v0.1 历史仍可读取。清空记录会同时删除计划和生成文件，保留用户原始资料、虚构样例及整理恢复日志。

## 计算与内容边界

统计最多处理 1,000 行、40 列；Excel 只使用首个工作表，多文件表头须一致。只接受完整数值和支持的常见单位，跳过编号、电话、日期与来源列，不计算公式或表达式；同列不同显式单位不合并。XLSX 使用已有缓存值，不执行公式。平均值保留两位小数。模型提取的数值仍需与原文核对。

查找用于展示相关片段，后续步骤仍读取全部已选资料；当前没有按某个人或某一条件自动筛选数据行的统计能力。长材料按片段选取。生成文稿可能遗漏或误解事实，日期、落款与核实承诺检查仅覆盖已观察到的模式。

达到单次生成长度上限时，结果和导出文件会注明“尚未写完”，应缩短要求或分段生成。已调整的计划要求保存在本机，重启后继续使用；后续执行仍由 worker 再次校验。

本版是有明确工具范围的办公 Agent。资料内的指令无法赋予 shell、浏览器、网络或额外文件权限。OCR、任意电脑操作、大表格分析与自动发送消息尚未实现。

## 验证与复用

31 项单元测试覆盖原有文件防护以及十进制统计、来源变化、计划编辑约束、失败重试和恢复。实际固定模型集成覆盖四步流程、431.70 元合计、143.90 元均值、CSV 直接统计、无资料写作与 worker 网络拒绝，详见 `qa/office-integration-report.json`。GUI 实测包含计划编辑、停止、跨重启续跑和不同成果预览；这些是开发验证，尚无真实非技术用户研究。

原生界面在 `Sources/Guiyu/AgentViews.swift`，执行器在 `backend/office_agent.py`，虚构材料在 `fixtures/office` 与 `fixtures/statistics`，可复跑脚本为 `scripts/check_office.py`。应用和工具保持 Apache-2.0；基础模型与第三方库遵循各自许可。

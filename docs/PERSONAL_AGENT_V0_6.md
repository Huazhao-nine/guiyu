# v0.6：个人工作流、成果与明确的使用偏好

归屿把资料处理延伸到持续的个人工作：对比方案、形成说明，过一段时间从成果中心找回原任务，再修改、写成邮件或另存副本。已有工作区语义检索、自动更新、条件统计、文件整理与模型切换继续保留。

## 体验一次

1. 工作台点“体验方案对比与写作”。两份场地方案全部为虚构资料。
2. 查看两步计划：逐项对比资料 → 起草与改写；开始执行。
3. 结果按费用、时间、设备展示原文和行号，生成对比 XLSX/Markdown、说明 DOCX/Markdown。
4. 左侧“工作成果”按任务、文件名或生成内容查找，可筛选文件格式、预览、保存副本。
5. 点“继续加工”回到原任务，填写修改要求，再拟定计划。原任务和成果保留，产生新的工作记录与文件。

文件夹工作区仍默认自动找资料；也可手动选定 2–6 份文档对比。对比维度最多 5 个。任务可组合查找、对比与写作，单计划最多六步。检索结果不足两份或超过六份时，会要求明确对比范围。

## 对比的依据

本地模型按用户关注点提出对比维度并摘取连续原文。程序检查资料编号、重复引用、摘录长度及原文逐字匹配，再生成表格。未知来源、改写的引文和未完整生成的结构不会发布。空白单元格显示“本次未提取到可核对片段”，不把它解释为全文不存在。每个有依据的单元格包含出处编号及原始行号，长文仍按上下文预算选取片段。

后续写作可以组织和概括这些结果，仍可能遗漏或错误推断；对比片段验证不等于写作全文事实验证，也不保证选段的相关性或完整性。数值总计继续使用专门的十进制统计工具，对比工具展示原值，不自行声称财务计算完成。

## 资料问答

资料型问答由模型从事先编号的原文片段中选择编号，应用只发布这些编号对应的原文、文件名和行号，不发布模型另写的事实性扩写。这样可避免把编号推断的年份、身份或外部背景写成资料事实。找不到对应片段会说明当前片段未找到答案。行筛选后的问答展示当前有效表格及同条件统计，表格预览最多 20 行，不重新混入被排除记录。

没有添加资料时，仍可进行一般写作与对话；需要自由组织语言时可用起草、改写或“写成简短说明”。来源型回答的表达偏好主要影响默认摘录数量，语气偏好主要作用于写作和没有资料的一般问答。选段仍可能遗漏或选错，尚无系统性回答完整率结论。

## 成果中心

成果按当前空间独立显示，包含原任务、生成时间、类型和生成时预览。当前工作记录最多保留最近 60 项；成果中心是这些记录的索引，不是对整台电脑的文件搜索。阶段性产物可以预览，原任务完成后才能继续加工。原文件已被外部修改时，历史预览仍是生成时快照；用本机应用打开或另存副本则使用实际文件。

预览、打开、定位和复制都校验当前空间的真实 `Outputs` 路径，拒绝符号链接和越界路径。保存副本使用系统位置选择器，复制不覆盖已有目标，不修改归屿中的原成果。继续加工沿用原任务资料和线程，执行前仍核对哈希；原资料变化后的工作区追问重新读取。

## 使用习惯

左侧“使用习惯”可明确保存默认语气、篇幅与最多 600 字备注。默认关闭，不从文档、对话或剪贴板自动归纳个人记忆。设置位于本机 `Guiyu/preferences.json`，适用于各工作区。当前明确要求优先于表达偏好，偏好不增加工具或文件权限。

每次新计划保存当时的偏好快照，修改设置从下一次拟定任务开始生效，不改变暂停任务。关闭后不向新任务模型发送偏好文本；“恢复默认”后保存会重置设置文件，旧计划中的历史快照随工作记录保留，清空工作记录时删除。

## 验证和隐私

新功能使用已有禁网 worker 和本机文件存储，没有新增网络服务、云端模型、账号或遥测。无需安装新依赖或下载新的模型。模型下载组件继续只负责固定模型准备，不接收任务内容。索引、成果和偏好仍未做应用级静态加密，用户主动另存到同步目录后遵循该目录设置。

`python scripts/check_personal.py` 使用真实默认 Qwen，在系统禁网策略下验证对比原文、三维度表格、写作、四个成果文件、偏好快照、同线程改稿及只发布原文的资料回答。原有查询、办公、工作区与直接流程继续回归。实机截图、GUI 和发行校验在 `qa/v0.6-*`。所有测试资料均为虚构，尚无真实用户研究、通用任务成功率或独立安全评审。

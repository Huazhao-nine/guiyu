# 非技术华语用户测试协议

状态为待执行。目前没有真实用户研究数据。测试前取得参与者同意，只使用虚构或主动脱敏的资料，不收集私人原文。默认不录屏、不上传使用日志。

## 参与者与任务

申请前争取邀请 5 位不从事软件开发的华语使用者试用，观察首次体验障碍。资助阶段计划累计 20 位，覆盖学生、行政或社区组织者等资料工作场景，记录简体或繁体偏好与设备规格。招募尚未进行，参与者可以随时退出。

1. 打开已经准备好的应用，独立找到示例入口，并说明文件在哪里处理。
2. 从三份虚构社区材料提取活动名、时间、地点和负责人，保存并打开表格，指出一个字段的出处。
3. 生成汇总，核对待办和未定事项，找到导出的文稿。
4. 预览文件整理，确认后检查新位置，再撤销并核对原文件。
5. 找到本地工作记录的导出与清空入口，解释清空后保留什么。测试时无需实际删除参与者数据。

主持人先不解释入口，卡住 90 秒后才按固定提示协助。记录独立成功、经提示成功或未完成，并按任务记录耗时、误点、错误理解和严重问题，不把每次点击作为独立样本。

## 拟定验收目标

- 准备好的设备上，至少 16/20 人无需主持人指导完成表格任务，首次成功中位耗时不超过 3 分钟。
- 至少 16/20 人能准确说明处理位置、外部软件边界与清空保留项。
- 所有已执行的测试整理均能在文件未被修改时恢复原内容，不丢失、不覆盖文件。
- 中文质量评测另建 30 组虚构资料，逐字段计正确、缺失和错误，摘要逐事实核对。目标字段正确率至少 95%，任何严重错引或文件损失都须先修复再发布。

这些数值是目标，不是已取得的结果。下载、安装和模型准备另测，不将预装体验替代首次安装体验。公开匿名问题类别、任务材料、汇总数据与失败案例；原始个体记录只在参与者允许范围内保存。

# 归屿35B默认模型与通用流程适配

0.25.0将Qwen3.6 35B A3B MLX 4bit作为默认搭档，32 GB Apple Silicon作为当前基础配置。推荐页只提供一个对话模型，检索与隐私识别组件分开展示。资料、推理、工具和复核均在本地，原文件修改仍需预览后单独确认。

## 本机使用与准备

退出原有归屿，再运行根目录的“打开归屿.command”。标准入口与32GB入口均打开 `dist/Guiyu-0.25.0.app`，不覆盖仍在使用的旧 `dist/Guiyu.app`。模型偏好已迁移为35B，首次打开新版会使用该模型。旧应用保持运行时启动器会提示先退出，不自动丢弃未发送内容或中断用户任务。

固定权重来自 `mlx-community/Qwen3.6-35B-A3B-4bit`，提交 `38740b847e4cb78f352aba30aa41c76e08e6eb46`，Apache-2.0。4份权重合计20,402,204,271字节，完整公共文件约20.429 GB，文件哈希在 `packaging/model-catalog.json`。本机复用GuiyuModels的Research目录，新设备安装到Installed目录；准备时完整校验后再登记，不复制第二份20 GB模型，不恢复旧4B。

新设备运行“准备归屿.command”安装固定Python环境及模型；资料处理与下载进程分离。界面可暂停、继续下载并核对安装状态。下载完成会替换初始占位项并启动已选默认模型，避免显示已下载却仍使用无效路径。已有显式导入的其他模型选择可以保留；本次本机旧权重清理来自用户单独授权，升级程序不自动删除其他人的模型。

原生与Python大模型准入均要求至少32 GiB内存，24 GiB在载入前拒绝。生产窗口为10,000输入、2,200输出token，结构化任务温度0，原生模板关闭推理模式，受限参数修复与16步工具上限保持。内存限制为MLX运行建议，不是整机强制上限。小模型兼容配置仅为显式导入与历史复现保留，不再提供16 GB默认入口。

## 通用适配机制

完整月度区间由真实公历计算，不以模型记忆或已有行值决定月底。检查绑定明确指定或唯一的真实日期字段，向规划器提供边界。对于明确整月、且没有额外日期限制的AND条件，复核实际日期端点并保存纠正依据；支持下一月首日之前等价写法。OR、NOT、额外明确日期条件与含糊字段不会被这一规则扩大。

明确选择类别的检查也作用于分组汇总，不能仅检查明细而让汇总混入其他类别。发现遗漏时，从同一已授权数据与保存的依赖图补充条件，重建相关交付；“单独列出／查看／统计／展示”等表达与实际文字值绑定，保留旧的复杂条件与单位。

对“回到刚才的某某任务”一类连续对话，来源仍由已核对父任务与资料快照决定，任务称谓不触发无谓的重新规划。只有改动短语、实际字段、比较符和值均明确，且其余要求可证明不变时，才修改已保存图中的局部边界；派生列、汇总、排序和副本一起重新计算。无法证明时回到一般工具规划，不猜值或执行任意代码。

修改中没有使用测试文件名、业务标签、年份、金额或标准答案分支。测试覆盖2024与2032闰年、月度边界等价写法、额外日期条件、否定／OR表达、分组后遗漏以及另一类任务称谓。

## 已执行的模型清理

用户明确要求后，删除其他对话模型的14个目录，合计101,754,397,052字节。包括归屿中的9B、4B与旧候选、测试目录的重复4B，以及LM Studio中的9B、27B与Gemma。保留35B、BGE、AstrLink Guard及OpenAI Privacy Filter；这些组件逐文件哈希核对通过。旧模型偏好私下备份，当前偏好只登记35B。

清理前检查没有LM Studio已加载模型、没有活跃旧模型任务或打开的旧权重文件；目录内均为模型权重、已知配置及缓存元数据。未广泛删除科学模型或Hugging Face缓存，未读取或改动正常工作区、文档与历史。移除文件体积约101.75 GB，当次磁盘可用字节增加约99.48 GB；APFS与其他进程活动会影响可用空间变化。

证据：`qa/v0.25/evaluation.json`、`model-cleanup.json`、`model-integrity.json`、`qa/v0.25-native-model-report.json`、`qa/v0.25-native-report.json`。初始与中间报告、输入、标准答案、源码冻结和历史发布存档均保留。源码包额外保存初始后端与中间后端，可在独立目录重放；重放历史候选需重新下载对应权重。

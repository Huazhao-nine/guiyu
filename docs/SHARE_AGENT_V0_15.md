# v0.15 对话式分享副本

用户可以直接说“把这份资料整理成可分享版本”，或“把客户跟进纪要.md整理成可分享版本，写一份简短跟进邮件，保留预算、截止日期和付款条件”。无需先去隐私页粘贴原文。

## 工作方式

归屿把分享请求送入授权资料流程。明确文件名时由工作区检索定位；“这份/当前资料”等指代优先使用本次已授权的资料范围。需要继承上轮来源时保留来源关系，不将普通旧聊天当成文件事实。

分享任务使用独立完整流程：读取本次选中资料的完整可读取正文，调用本地隐私模型和规则；默认完整保留脱敏后的文字，若明确要求摘要、润色、说明或邮件，则只向本地对话模型提供已经脱敏的资料与要求。文稿经过数字、条件和交付复核后再扫描。第一次检测识别到且已从正文移除的敏感值只在内存中用于最后的字面复查，必要时补遮，不保存还原映射。

已遮盖的标准占位符不被反复当作新密码。保护金额值和明确的金额字段名，以及关闭私人日期时的常见办公日期；明确标注的密码和自定义词仍优先。模型和规则可能漏检或误判，检查通过并非匿名化保证。

仅在检查通过后才生成TXT、Markdown和Word，三种格式都来自同一份脱敏正文。导出文件用固定名称“可分享副本”，不带入原文件路径、原文件名、原附件或文档元数据。结果卡显示处理资料数、识别组件、类别计数和检查说明，正文即可预览和复制。原文件没有改动，不创建文件修改事务。

## 设置与边界

分享任务默认使用AstrLink Guard；隐私页选择OpenAI Privacy Filter后沿用该组件，不静默降级。所选组件未就绪、损坏、忙碌或超时会停止交付。用户可在隐私空间下载组件。

分类开关改为仅在本机记住，分享任务使用发起时的分类快照。额外遮盖词可以在当前要求中明确写成“额外遮住‘某词’”；隐私页的自定义词、密钥前缀和保留名单仍只用于该页当次检查，不自动写入对话设置。固定规则继续补充邮箱、手机号、常见密钥、校验通过的证件和有银行卡上下文的卡号。

一次支持1至8份资料、合计20,000字符以内的完整可读取正文。不会把检索片段或普通问答的截断内容当作完整副本；超过范围、部分文件读取失败或表格存在未读行时暂停。复制的是文字层，图片、扫描识别、页眉页脚、脚注、批注和附件不作为已处理内容，版式与表格布局不保证保留。用户需要复核预览。工作区统计和其他一般工具继续存在；分享流程当前封装为独立的资料→脱敏→可选写作→复查→导出流程，不允许混入未检查的普通导出步骤。

工作记录仍是本机私有记录，可能包含用户原话、来源路径和本地原文预览；它不是可对外分享的匿名记录。此功能的脱敏边界是分享正文和三种副本，而不是整个私有工作区或历史。不会自动发送或发布结果。修改原文件仍需独立预览和确认。

## 验证

`tests/test_share_agent.py`覆盖完整读取、大小限制、读取失败、残留补查、检测不稳定时阻断、数字边界、写作失败不伪装成功、分享步骤不可跳过以及三格式正文不含预期隐私。

`scripts/check_share_agent.py`在拒绝网络的沙箱中使用已安装Qwen3.5 9B、BGE、AstrLink/OpenAI固定模型，测试完整副本、脱敏后邮件和OpenAI副本。最终3/3通过，实际源码校验值一致。最初和中间失败保留在版本化报告中。固定虚构开发案例不代表一般任务成功率、真实用户测试或16GB硬件验收。实际M5 32GB，主进程MLX/RSS峰值约5.7GB，二者重叠；子进程隐私组件占用另计，不能据此推断整机峰值。

本轮已构建原生应用并通过原生状态/序列化测试。计算机使用工具未获准访问隔离验收应用，所以没有执行v0.15点击流程和新界面截图，未将其记为通过。三格式成果已通过真实后端执行与文件内容核对。

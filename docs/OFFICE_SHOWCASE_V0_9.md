# 日常办公样例工作区

在首页点击“体验办公样例工作区”，归屿会在本机创建18份虚构资料的独立副本，自动建立索引。点击任务卡片只填入要求，可以修改后拟定计划、检查步骤，再开始执行。再次打开会使用原副本，不覆盖你在样例中做过的修改。

## 可以体验的工作

| 场景 | 操作 | 核对重点 |
| --- | --- | --- |
| 会议跟进 | 纪要转成团队邮件 | 三位负责人的任务、截止时间、缺失链接 |
| 条件统计 | 星桥项目、待报销、金额大于100元，按经办人分组 | 林晓128.50元，陈雨460元，周宁120元 |
| 连续追问 | 在统计结果后输入“那陈雨呢？” | 保留原条件，陈雨仍为460元 |
| 日期范围 | 只统计2026年10月的待报销费用 | 林晓165.30元，陈雨376.40元，周宁120元 |
| 项目简报 | 综合周报和客户沟通记录 | 区分完成、进行、阻塞与待确认，不能声称已验收 |
| 采购比较 | 对比青松与远山设备 | 2800/3200元，交付5/3个工作日，质保12/24个月 |
| 硬条件 | 500元以内、25人、投影仪 | 两个场地都不合格，不能放宽条件 |
| 制度查找 | 查报销期限和审批要求 | 10个工作日，超过500元需要项目负责人审批 |
| 付款说明 | 依据合同条款起草说明 | 签署、发票、验收是条件，尚未满足，不能虚构已付款 |
| 请假申请 | 按流程起草待审批申请 | 交接人、待补原因与审批状态 |
| 缺失记录 | 查找ZXQ654321 | 保留精确编号，没找到就停止写作 |
| 整理文件 | 两份票据分类命名预览 | 先预览，另行确认才修改原文件 |

“按条件统计”卡片没有限定月份，陈雨460元包含9月的180元；日期范围卡片仅统计10月，陈雨为376.40元。这是有意保留的口径差异，避免把一份正确的小计误写成另一个范围的结果。

## 资料与本机控制

样例覆盖行政、财务、项目、采购、合同、制度与待整理票据，使用可直接查看的Markdown、文本与CSV。生成结果支持本机预览与DOCX、XLSX、Markdown导出。样例文件、索引和任务留在本机；处理进程不联网。真实工作中可在工作区选择器选自己的文件夹。

样例入口不会自动执行任务、付款、发信或修改原文件。所有姓名、制度、合同、数字和日期均为虚构功能演示，不能当作真实组织制度。

复跑任务和冻结期望值在 `fixtures/office_showcase/tasks.json`；原始资料在 `fixtures/office_showcase/workspace/`，文件哈希在同级 `SHA256SUMS`。这些是开发样例，不代表真实用户完成率或所有办公需求已覆盖。

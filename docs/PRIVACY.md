# 归屿隐私与安全边界

## 当前保障

- 应用启动后禁止 network 类操作，Python 子进程继承。应用和 worker 各自验证拒绝结果，未隔离时停止任务。与 worker 的 JSONL 通信使用匿名管道。
- 只从显式选择的文件或文件夹收集支持格式，拒绝符号链接、超限输入与无效整理来源 ID。文件夹选择授权包含其支持格式的后代文件。
- 文档内容被当作不可信输入，模型不能调用 shell、请求网络或扩展资料范围。Office 文件按文档结构读取，不运行宏。压缩文件解压尺寸受限。
- 改名必须由使用者确认。执行前核对源文件哈希、目标冲突、路径范围；原子改名不覆盖现有目标。撤销前核对目标内容，避免覆盖用户后续修改。
- 表格对以公式字符开头的内容转义，防止生成表格激活外部公式。
- worker 环境变量为白名单，不继承 API Key。应用不启用遥测、自动崩溃上传或云端模型回退。
- v0.7 计划只使用九种已注册工具（含资料对比），初始规划最多六步、连同自动补查最多八步。用户只可调整未完成步骤的要求与开关，不能通过计划注入新工具或扩大文件范围。筛选接受受约束的字段比较，不执行表达式、代码或 Office 宏。
- 规划时固定资料路径及 SHA256，每一步前复核。继续任务复用已完成结果，仅重新执行被中断的步骤；文件整理仍单独预览与确认。

## 存储与退出

| 位置 | 内容 | 清空记录时 |
| --- | --- | --- |
| Guiyu/history.json | 对话、结果、资料名称路径与短预览 | 重置 |
| Guiyu/pending-plan.json | 尚未结束的任务计划、资料路径和步骤要求 | 删除 |
| Guiyu/Plans | 资料哈希快照、步骤记录、已完成结果与中断保存点 | 删除 |
| Guiyu/local-models.json | 模型目录、名称与当前选择 | 保留 |
| Guiyu/preferences.json | 用户明确保存的表达偏好，默认关闭 | 保留，可在使用习惯中恢复默认后保存 |
| Guiyu/Outputs | 生成文件和任务结果 JSON | 删除 |
| Guiyu/Transactions | 文件整理路径和内容哈希、恢复状态 | 保留，以便恢复 |
| Guiyu/Examples | 内置虚构资料的工作副本 | 保留 |
| 用户选择的原始位置 | 原始资料，可能按用户确认被分类改名 | 不删除 |
| GuiyuRuntime | Python 依赖和固定模型 | 保留 |

上表路径均相对于本机 Application Support。可在应用的“隐私空间”打开本机存储或导出工作记录。清空操作涉及文件删除，执行前应用显示确认。本地明文和文件权限不等于静态加密或安全擦除；系统备份可能保留副本。

v0.3 计划还保留线程、原始表格、筛选条件和分组，以便继续追问和重新计算；随工作记录清空一并删除。导入模型保留在使用者选择的目录，清空任务不会删除权重。切换模型重启同样禁网的处理进程，不启用自定义模型或分词器代码。独立模型准备脚本可联网下载固定提交，不接受任务路径，不读取或上传任务记录。

## 保证范围

当前保护针对归屿应用和它启动的处理进程直接联网。已经控制操作系统的恶意程序、同账户访问、截屏、系统崩溃服务、云备份和用户主动打开外部软件不在当前边界内。网络探针是回归证据，不能证明整个操作系统没有流量。

网络限制使用已弃用的 Seatbelt Sandbox 接口。当前 M5 实机有效，后续交付应迁移到受支持的 App Sandbox/XPC，并验证 macOS 系统版本。文件范围由程序实现，当前并无完整的 OS 文件系统最小授权。文件检查存在通用的并发修改与崩溃恢复边界，需要独立安全评审；不宣称通过形式化验证。

导入扫描 PDF 不会执行 OCR。模型可能误读、遗漏或生成错误；出处编号、原文匹配和可撤销操作帮助检查，不构成事实正确性保证。十进制统计针对实际输入值精确计算，但上游由模型提取的字段仍需核对。写作对已观察到的无依据日期、落款与核实承诺做规则检查，不能替代完整事实审查。重要决策需核对原始材料。

## v0.4 模型下载与工作区

主应用与 worker 继续禁网。通过 LaunchServices 启动的独立下载应用仅接收固定模型编号与动作，不接收资料路径、提示词和历史。下载应用以额外文件策略拒绝个人记录、用户配置、桌面和挂载目录的内容读取，仅对模型目录开放写入，使用固定 HTTPS GET 与逐文件 SHA256 校验。下载源与 CDN 会看到 IP 地址及所选模型。实测与边界详见 [v0.4 说明](MODELS_AND_WORKSPACES_V0_4.md)。

每个自选文件夹工作区独立保存历史、计划、结果和资料选择。切换时重置线程及查询状态。工作区清单只遍历受支持文件的路径与元信息，内容由选中后的禁网 worker 读取。原文件保留原处，整理仍须确认。目录遍历边界、内容读取范围和用户主动导出后的边界均在界面或说明中给出。

## v0.5 工作区索引

选择工作区即授权在本机建立其支持格式的内容索引。独立 Python 索引进程继承并探测网络拒绝；固定 BGE 模型以 MLX 本地编码，不使用在线 API 或模型自定义代码。文档片段、向量和哈希存于该工作区本机 SQLite 文件，未做应用级加密。新问题前校验文件状态，执行步骤前后核对哈希；文档变化后的追问重新读取，旧工具结果不进入本轮事实上下文。

“清空索引并暂停”清空索引内容并停止自动更新；原文件和历史任务保留，点击建立索引恢复。SQLite secure_delete 不等于擦除系统备份或快照。工作记录清空与索引清空分别控制。手动资料的预览、规划与执行也校验当前工作区边界，防止目录换成链接后越界读取。详细范围与验证见 [v0.5 说明](WORKSPACE_RETRIEVAL_V0_5.md)。

## v0.6 个人工作与成果

资料对比只把通过逐字匹配的原文放入表格，资料问答只显示模型选择的已编号原文；生成性写作仍需核对。成果搜索局限于当前空间最近保留的记录，打开和复制校验真实 Outputs 路径并拒绝链接，不扫描其他用户目录。保存副本不覆盖已有文件，用户主动保存到外部软件或同步目录后的处理遵循原有边界。

使用习惯由用户明确保存，默认关闭，最多600字备注；不会从资料或对话自动提取个人记忆。偏好只影响表达，当前要求优先，不增加工具与文件权限。新计划保留当时快照，旧计划的偏好副本随记录清空删除；设置文件可单独恢复默认。详细交互与范围见 [v0.6 说明](PERSONAL_AGENT_V0_6.md)。

## v0.7 自主协作

规划、执行反馈和输出修复均使用当前本地模型，进程继续禁网。自动补查只能使用本轮已授权的资料路径和注册工具，最多增加两个步骤。自动修复只针对允许的输出错误，不跨越资料变化、权限或路径错误。原文件整理的执行接口不在自主控制器可调用工具中，仍须预览后单独确认。

活动记录、步骤检查和修复提示存入原有本机任务计划，随工作记录清空。检查只约束输出结构、原文引用与文件状态，不保证一般语义、内容完整性或资料真实性。新增模型沿用固定下载组件、完整性校验与无自定义代码策略；下载模型权重不授予模型额外能力。详情见 [v0.7 说明](ADAPTIVE_AGENT_V0_7.md)。

## v0.8 文稿质量与更多架构

金额、对象、币种和已识别条件检查使用当前已授权原文、匹配行与程序计算，不引用旧轮次草稿作为事实。对比由模型选择原文编号，程序渲染原句。有限修订后仍有疑问时，只交付明确标注的原文依据版；该路径不绕过原文哈希、权限或文件边界，也不能修改原文件。

GPT-OSS、Qwen3.5和Gemma4使用既有MLX本地进程及禁网策略，没有远程推理、云端复核或遥测。reasoning/thought通道不进入工具解析或用户正文。调试追踪只在开发脚本明确指定 `--trace` 且使用虚构测试材料时启用，应用默认关闭；`qa/private`不进入交付包。新增模型仍采用固定文件清单和SHA256，并关闭自定义模型与分词器代码。见 [v0.8 说明](QUALITY_AND_MODELS_V0_8.md)。

# v0.8：复杂任务质量与本地模型选择

归屿继续面向普通华语使用者。输入目标、查看计划、开始执行；资料读取、检索、规划、文稿复核和推理都在用户电脑上完成。文件整理仍先预览，单独确认后才能修改原文件。

## 本轮质量改进

**完整目标贯穿写作和复核。** 模型安排的某一步可能只写“生成说明”，原目标中的预算、人数、设备要求仍会进入生成和复核。文档比较中的预算条件不再自动当作表格行筛选，避免额外提取和不适用的统计。原目标明确要求成稿时，程序可以将误标为问答的写作步骤补正为写作；仍须通过工具与依赖验证。

**对比直接选择原文编号。** 模型选择来源片段，程序把原文填进对比单元格，不再要求模型逐字重新打出引文。片段必须属于指定来源，未知编号、跨来源编号和额外字段会被拒绝；行号由原文位置计算。

**程序核对可识别的金额和条件。** 核对文稿金额是否来自当前资料或程序计算、是否对应正确对象、币种是否一致，以及费用高低结论、明确预算上限、预算优先建议和已识别的取消限定。同时检查已识别的参加人数、场地容量和必须提供的设备。承认超预算不能使正面的推荐变成合格结论；用户要求不放宽条件时，也不能在正确判断无合格方案后继续建议调整预算或人数。筛选后只使用本轮匹配行，旧轮次和排除行不能提供金额依据。差价仅在币种与计费口径相同、表述明确为差价时由程序计算，并把计算依据交给本地复核器。提取表格中带来源和可识别币种的金额也会与对应原文检查。

**精确修订后再检查。** 程序检查与本地复核的问题合并交给修订器。修订器只返回草稿中可唯一定位的原句替换，最多6处，每处新旧内容不超过800字符；不允许模糊匹配、重叠修改、路径或执行指令。修改后重新检查，避免整篇重写把其他正确内容改错。复核器要求引用实际存在的错误句子，不会因原目标未要求的可选补充项而阻断交付。

**失败后保留有用依据。** 输出不完整、格式错误、未通过金额/条件检查或本地复核时，只修订当前步骤，保留前序结果。一次执行最多重试一次，单步骤累计最多三次。写作连续修订仍有疑问时，生成明确标注的“依据版”：保留原文和程序计算结果，选择建议与最终结论待确认。界面不会把它显示成所有要求已完成，也不会自动增加一轮问答来冒充最终成稿。原文变化、权限、磁盘或路径错误仍停止，不通过依据版绕过。

以上程序规则针对可识别的金额、对象与条件，不是任意自然语言事实的形式化证明。复杂计费口径、间接条件、引文相关性、资料真实性和一般语义仍可能遗漏；本地模型复核也可能误判。重要结论保留出处供核对。

真实控制器的三份注入错误草稿实测：最终运行中金额错配自动纠正；取消限定与预算结论分别交付依据版，共1份纠正成稿、2份依据交付，未发布原始错误文稿。该测试验证保护路径，不表示每次修订都能完成自然语言成稿。详见 `qa/v0.8-repair-integration-report.json`。

## 模型库

新增 Qwen3.5 9B、Gemma 4 E4B、GPT-OSS 20B 的固定 MLX 版本。三者均已实际下载、逐文件 SHA256 核验，并在禁网进程执行同一组中文开发用例；不是只验证模型能加载。归屿只接入文本资料处理，模型原有的视觉或音频能力不代表此版本已有相应界面。

模型库提供日常推荐、较省内存的进阶选择与快速体验入口，其余经典模型放在“更多模型”。下载和切换继续由界面完成，用户无需准备文件夹。推荐依据与未实测的候选见 [本机模型比较](MODEL_SELECTION_V0_8.md)。已有模型选择不会被升级自动更改。

GPT-OSS 的 reasoning/final 和 Gemma 的 thought/正文输出经过适配。推理通道不进入工具 JSON、文稿或实时显示；未产生完整正文时不发布思考片段。GPT-OSS 使用 low reasoning，并为内部推理额外保留有界 token 预算。其他参测模型关闭 thinking。无云端回退。

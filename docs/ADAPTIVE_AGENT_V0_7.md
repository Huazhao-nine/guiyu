# v0.7：本地自主规划与工具协作

归屿默认开启“智能协作”：先在本机把目标拆成步骤，开始后逐步检查输出，结合中间结果补查，遇到可恢复的模型输出错误时调整要求重试。资料和推理仍全部在本地；任何文件整理只生成预览，确认执行继续使用原来的独立入口。

## 普通用户如何使用

在工作台点击“体验智能协作”，用两份虚构场地方案体验：对比费用和设备 → 核对取消规则 → 形成说明 → 文件整理预览。也可以对自己的已授权工作区直接交代完整目标。查看计划后开始，执行卡片会显示当前步骤、检查结果与简短动态，可展开查看补查和恢复记录。

智能协作能在原资料范围内补充最多两个步骤，单任务总计最多八步。源文件发生变化、关键资料缺失或超过边界时，保留已有成果并说明原因。无匹配资料时暂停后续写作，点击“补充要求”提供信息后重新规划。可在输入框菜单关闭“执行中检查与调整”，按原固定步骤执行。

## 规划与调整

- 初始规划使用当前本地对话模型。模型只返回允许工具与每步要求，不接收 shell、网络或任意文件路径权限。一般初始计划最多六步，为补查留出空间。
- 数值条件仍由现有类型化查询编译器处理。筛选必须先于统计，文本统计先提取表格，不允许模型增加未要求的统计。文字条款核对使用资料问答，整体要点整理使用摘要。
- 规划缺少必要工具、格式不完整、工具未知或依赖不成立时，退回已识别的目标步骤。不会执行未经验证的模型计划。
- 每步结果之后，结合原目标、当前结果、已完成与后续步骤，由本地模型提出继续、补一步或请求补充。提出的动作再次校验，拒绝未知工具、自动整理、重新启用用户关闭的步骤，以及使已筛选表格失效的操作。
- 自动补查不会增加路径或读取新的工作区。查找零命中时可以在原授权范围内换短关键词重试；保留明确的字母数字编号，不能丢掉编号后用泛词冒充命中。相关性仍需核对，不能据此宣称语义召回完整。
- 补充最多两个步骤，模型反馈最多三轮；每一步在一次执行中最多重试一次、累计最多尝试三次。达到边界会保留进度，避免无限执行。

## 检查与失败处理

检查包括工具输出结构、完整结束标志、表格列结构、已验证的对比原文，以及成果文件存在、非空、位于当前 Outputs 范围且非符号链接。原文哈希在每一步和每次重试前后核对。检查不等于所有结论事实正确，也不是独立安全审计。

有资料的智能协作写作在发布前增加本地模型复核，侧重数字比较、标题与正文矛盾、遗漏限定条件和当前要求。复核器只返回接受或具体修正理由，不能改文件、增加工具或直接发布新正文；需要修正时使用同一步的有限重试预算。复核格式无效或未完整时，界面明确显示“内容复核未完成”，只保留结构与文件检查结论。本地模型复核仍可能漏检或误判。

可恢复情形包括模型返回不完整 JSON、对比引文未找到原文、回答选择未知片段、文稿达到输出长度上限等。自动重试会保留原目标，附上具体格式问题，重新生成该步骤；此前完成的步骤不重跑。第一次未通过的输出不会列为已完成成果。失败尝试的内部输出可能仍在本机 Outputs 子目录，清空工作记录时一并清除。

原文变化、权限错误、磁盘或路径边界错误不自动重试。匹配行为空且后续需要写作时，保留空结果，要求调整条件或补充资料。无法恢复时保留失败步骤和已完成结果，允许调整要求后继续，达到累计尝试上限后需要重新规划。

原文件改名和分类仍通过事务预览、显式确认、执行与撤销完成。规划器、反馈器和自动重试均不能调用执行原文件改名的接口。

## 更多本地模型

模型库保留简洁的日常推荐，新增“更多模型”折叠区。三项新下载选择均采用 Apache-2.0 许可的固定 MLX 版本，文件清单记录大小及 SHA256：

| 选择 | 下载大小 | 内存起步估计 | 使用定位 |
| --- | --- | --- | --- |
| [Qwen3 0.6B](https://huggingface.co/mlx-community/Qwen3-0.6B-4bit) | 351.4 MB | 2–4 GB | 极简试用，复杂目标使用4B或更大模型 |
| [Qwen2.5 7B Instruct](https://huggingface.co/mlx-community/Qwen2.5-7B-Instruct-4bit) | 4.30 GB | 8–13 GB | 中文写作与资料处理的另一种选择 |
| [Qwen3 14B](https://huggingface.co/mlx-community/Qwen3-14B-4bit) | 8.32 GB | 16–22 GB | 较大容量备选，加载与生成可能更慢 |

内存为估计，随上下文、工具与系统占用变化；不代表三者均已做复杂任务质量或性能对比。0.6B已通过界面真实下载、独立逐文件哈希核验、切换和基础中文回答。7B与14B已核对固定版本、配置、分片及完整性清单，尚未在此机器下载运行。默认日常推荐继续为已实测的Qwen3 4B。

下载由独立组件完成，不接收任务资料；它仅联网获取固定模型文件。实际任务进程与索引仍禁网，不使用云端模型或向量服务。新增模型不需要新账号、额外模型目录操作或安装新的 Python 依赖。

## 实测范围

`scripts/check_adaptive.py` 使用真实 Qwen3 4B、虚构资料和系统禁网策略，检查模型规划、工具协作、逐步检查、执行反馈、预算上限、零命中暂停、资料变化停止，以及原文件仅预览。输出错误注入、恢复次数、补查步骤顺序与用户关闭步骤等情况由 `tests/test_agent_control.py` 独立验证，不能把注入测试当成真实模型任务成功率。

原有查询、办公、工作区、个人工作和直接流程回归继续保留。GUI 证据、模型下载核验、截图和发行检查见 `qa/v0.7-*`。这些均为虚构任务开发验证，尚无真实用户任务完成率、系统性模型比较或第三方安全审计。

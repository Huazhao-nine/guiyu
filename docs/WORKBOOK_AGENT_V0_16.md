# v0.16 对话式工作簿处理

后续入口已在v0.17升级为“通用工作簿示例”，见`WORKBOOK_ENGINE_V0_17.md`。本页保留v0.16当时的使用与验证范围。

直接说“在我给你的工作簿 1 文件中，把计算技术研究所的同学的名单分离出来，发给我”。归屿在已授权范围内定位工作簿，检查各工作表和表头，把条件转成明确的字段比较，逐行筛选，展示名单并生成 Excel、CSV 副本。原工作簿不改动。“发给我”表示在本机交付副本，不会发送邮件。

## 本轮改进

- 识别“名单、分离出来、挑出”等自然说法；“计算技术研究所”不会误触发算术工具。
- 指定“工作簿 1”可以匹配“工作簿1.xlsx”；不会把工作簿10当成工作簿1。同名文件来自不同目录时，要求明确选择。
- 检查最多30张工作表，识别前20个非空行中的表头；支持标题、空行、重复表头和字段顺序不同但字段集合相同的数据表。单列说明页与空表会明确列为未参与数据筛选。
- 实际纵向合并单元格的值按合并范围展开；普通空白不猜测继承。保留同名不同学号记录，不自行去重。
- 先用可核对的字面条件；无法可靠理解时由本地模型依据真实字段翻译成有限的筛选表达式，并检查条件覆盖。模型不会直接生成结果行。新条件值必须出现在用户要求中，或来自已有条件。
- 纯筛选/统计目标只提供对应数据工具，避免模型为简单名单额外生成未请求的文稿；明确需要写作时仍可组合。
- 自然名单请求在规划时检查是否遗漏年级、状态、否定等行条件。文件、工作表选择与行筛选分别核对。
- 可说“只保留姓名、学号”，筛选后导出指定字段；后续追问仍保留完整原始表格，支持“那软件研究所的同学名单呢？”
- 导出后重新读取 Excel 单元格，与程序选中的记录逐格比较；学号等标识保留文本，公式前缀转义。CSV 使用 UTF-8 BOM。学号、工号、账号、邮编不会参与加总。
- 对话中给出匹配条数、最多20行预览、读取范围。零匹配保留空结果与表头，不返回整张原表。单步筛选也有明确的交付检查状态。

## 使用

在办公样例页点击“从工作簿分离同学名单”，会创建独立的虚构工作区。示例包含说明页与两班学生，共11条记录，计算技术研究所匹配6条。按回车发送，Shift+回车换行。可继续追问：

1. 那软件研究所的同学名单呢？
2. 从工作簿1里挑出计算技术研究所且年级为2025级且状态为已确认的同学名单。
3. 把工作簿1中计算技术研究所的同学名单分离出来，只保留姓名、学号。
4. 把工作簿1中计算技术研究所的同学名单分离出来，统计补助合计。

## 范围

本轮沿用单次合并不超过1,000条记录、40列、工作区最多40份文件的限制。异构数据表不会被静默丢弃；请指定具体工作表或统一字段。尚未实现任意表格布局、跨表关联、复杂排名或任意脚本执行。遇到缺少计算缓存的公式会停止，请在表格软件中重新计算并保存副本。只读取单元格文字与计算缓存，不执行宏或外部连接。

运行基线仍为16GB Apple Silicon，日常9B与轻量4B模型选择不变；本轮实测是M5 32GB。模型判断、检索、筛选、导出和检查均在本机，资料工作进程禁网。修改原文件仍沿用原有预览及独立确认。

## 验证入口

- `tests/test_structured_tables.py`：自然条件、跨表、字段投影、真实行定位、同名记录、原文件哈希、公式缓存与公式转义。
- `scripts/check_roster_agent.py`：7个固定虚构任务，真实本地9B+BGE，独立QA数据与禁网子进程；报告为`qa/v0.16-roster-agent-report.json`。
- 首轮失败与修复前报告保留，不把后续通过覆盖为“从未失败”。这组开发回归不代表任意工作簿都能成功，也不是用户真实工作簿验收。

# 归屿0.27.1提交演示说明

归屿面向非技术华语使用者，在授权工作区中查找资料，组合表格、计算、日期、写作和隐私工具，交付可预览与导出的副本。当前路径为Apple Silicon 32GB，默认Qwen3.6 35B A3B MLX 4bit；实测设备为M5 32GB、macOS27.2。资料和推理全部本地，原文件变更仍需预览和独立确认。

## 打开演示

自行退出旧版归屿，然后双击根目录“打开归屿.command”。新设备先运行“准备归屿.command”；准备阶段下载固定公开组件，独立下载器不接收资料或对话。模型权重与Python环境不在发布ZIP内。应用使用临时签名，尚未做Apple公证，当前不能把其他系统版本和设备称为已测环境。

首页打开“归屿演示工作区”。四份虚构资料覆盖支持日志、原安排、最新通知和客户纪要。选择目标后按Return发送，Shift+Return换行；中文输入法选词不会发送。目标入口只填入普通中文请求，仍走同一套检索、规划、工具与交付流程，没有按文件名返回答案的分支。

1. 工作簿汇总：多表有序合并、按编号保留首次记录、组合条件与半开日期区间、小时和万元展示、排序与Word交付。
2. 短追问与返回：要求只保留第一名，插入普通聊天，再回到第一名结果导出Word。只改交付格式时，重放来源和最终数据证明，保留原条件、列、单位与排序。
3. 费用与日期：结合最新通知和沿用规则，核对费用、余额和最晚确认日期；可退押金单列，保留未付款状态与出处。
4. 分享副本：本地AstrLink Guard与规则识别虚构姓名、地址、联系方式和密钥，复查后输出TXT、Markdown与Word，保留预算、办公日期和条件。OpenAI Privacy Filter仍为独立可选组件，本轮不声称重新测量它。

## 此次修复

完整目标、工具步骤和规划提示分开保存。算术步骤只核对数值，日期步骤单独保留并先于文稿；模型提示不能授权新的数字或日期。动态添加步骤继续从原目标派生要求，用户手动修改的要求另有来源标记。

当参数规划器重复请求已成功的同一工具，程序转入独立交付复核。结果不足时继续补做，不因重复就自动放行；失败调用也不能被当作已完成。复核格式失败时直接修复复核响应，保留工具结果，避免重算。

文稿复核使用受限JSON和实际草稿行作为引用范围，减少无效结构与不存在的引用。有效局部修改后若仍有具体问题，优先再次局部修订；不能形成有效修改时才重新成稿。原有三次写作尝试上限保留。修改前另行核验复核意见是否被用户要求、实际草稿和来源支持，避免将可选历史对比或已存在的字段当作漏项。尚未付款也不能自动变成“确认后付款”等来源未给出的新流程。

实际模型曾把正确的乘积、日期和星期误判为错误，甚至在理由里同时承认原值正确。现在向复核器提供重新执行的实际计算、子表达式与日历结果。只有批评与这些证明直接矛盾时，程序才排除该项算术误报。单价选择、来源版本、单位、计入范围、缺项与工作日规则不被这条规则豁免；原有金额、日期星期、退还条件及文件范围检查继续执行。模型复核仍不等于独立审计或全面正确性证明。

## 构建与复现

```sh
zsh scripts/build_model_demo_v27_1.sh
python -m unittest discover -s tests -q
zsh scripts/check_native.sh
python scripts/check_delivery_reuse_v27.py
```

构建输出独立的`dist/Guiyu-0.27.1.app`。Python使用安装了`requirements.lock`的环境。CPU回放只验证完整OfficeAgent导出复用与来源证明，其中编辑事实选择使用桩，不能代替模型或界面验证。

已准备35B和BGE后，可用GuiyuRuntime的Python运行`python scripts/check_submission_patch_v27_1.py --label reproduction`，在新的独立虚构工作区内执行禁网的检索、规划、核算与写作。评分期望值只在执行后读取，不传入模型。大模型任务应串行运行。

`scripts/package_publication_v27_1.py`生成独立发布包，`scripts/check_publication_v27_1.py`从源码ZIP重新解包，执行程序与原生检查、CPU回放、独立构建、签名及禁网探针。包中不包含模型、运行环境、正常历史或私有原始轨迹；保留与早期报告对应的后端快照。

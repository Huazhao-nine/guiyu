# v0.12 本地计算、日期与连续任务

归屿可以根据中文目标自行使用本机计算和日期工具。它们不依赖资料工作区：索引暂停、没有添加文件时，也可以计算平摊、预算、折扣和比例，或核对相对日期、星期与日历天数。

## 体验

在示例工作区点击“算一笔平摊费用”或“确认下周五日期”，也可以直接输入自己的问题。例如：

- “午餐368元、交通125.5元，3个人平摊，每人多少元？保留两位小数。”
- “收纳盒199元，买3个打八五折，最后加20元运费，合计多少？”
- “三笔费用158.6、89.9、32.5元，三人均摊。”接着问“改成四人呢？”
- “从今天起14天后是哪一天，星期几？”
- “10月22日到10月31日相隔多少天，含首尾又是多少天？”
- “预算3600元，场地1200元，物料35元买24份，交通480元。计算已花和剩余，导出Word说明。”

模型选择工具与参数，计算结果和日期结论由程序直接展示。工具卡默认给出简短结果，展开可查看算式、参考日期及核对结果。结果和工具轨迹保存在本机，对话可以继续；Word和Markdown均生成副本，保存在当前空间的工作成果中。

## 正确性与协作

计算工具只接受有界的十进制四则运算与括号。它从原始数字文本构造精确有理数，最终显示时才按要求四舍五入；不能执行模型写出的代码，也不支持函数、幂、整除或任意表达式。除零返回明确错误，不通过擅自修改除数“修复”。

精确中间运算限于同一条算式；跨轮追问目前可能沿用前轮已显示的舍入值。例如先算“1÷3，保留两位”，再说“乘以3”，可能得到0.99；同一算式“(1÷3)×3”则得到1。需要避免累计舍入时，请合并算式，或明确指定下一步以原算式还是显示值为基数，并在工具卡核对实际使用的算式。

模型参数中的数字必须来自用户输入或经重新验证的历史工具记录。普通助手文字、失败调用、显示精度和其他实现字段不能提供新的金额或人数。自由生成的含数值主结论不会覆盖程序结果，避免把输入金额冒充合计，或在整理文稿时改错数字。

相对日期使用本机日期锚点，周一为一周开始。“下周五”调用某周日期工具，不让模型猜一个日期；日期参数检查已有日期、前后方向和明确周条件。日期差为结束日减开始日，不计起始日；明确要求首尾均计入时，另计算绝对间隔加一天。这里提供公历日历天，不推断法定节假日、调休或地区工作日。

一次任务最多执行4次工具，模型决策最多6轮。收到参数错误后可在原目标范围内调整；结束前最多核对两次交付，发现用户明确要的结果尚未核对时继续补做。补做要求必须引用当前用户原句。仍未核对整项目标时保留已有结果并说明状态，不把已执行一个工具等同于整个目标完成。

## 隐私与范围

工具只接受数字和日期，不接受文件路径、网络地址、shell或Python代码。资料与推理、工具执行和检查保持本机禁网运行。历史工具回放只读取当前对话在真实Outputs目录中的记录，检查身份、线程、符号链接与条数，并重新执行核对；工作区事实仍走原来的检索与来源快照流程。

本轮新增依赖仅为Python标准库。16 GB基础配置、9B日常模式与4B轻量模式继续使用既有内存策略。新能力不会发送邮件、创建系统提醒或控制其他应用。修改原文件继续先给预览、另行确认。

## 开发验证

固定用例为 `fixtures/general_tools/tasks.json`，真实模型入口为 `scripts/check_general_tools_agent.py`。验收用固定日期2026-10-22，期望“下周五”为2026-10-30；实际应用使用本机当前日期。模型报告为 `qa/v0.12-*-general-tools-report.json`，原生界面报告为 `qa/v0.12-gui-report.json`。

开发机为M5 32 GB，使用16 GB运行策略。固定开发用例与原生验收不代表任意自然语言条件都能正确理解，也不能替代16 GB实机、非技术用户研究或独立安全审计。

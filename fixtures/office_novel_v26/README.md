# 新办公资料与冻结目标

这里的工作簿、CSV和活动文字使用虚构数据。公开台账、公开报价保留了公开高校表格的版式，填充值、机构及人员均为测试用途。目标、独立计算的预期值和文件哈希在模型首次执行前冻结。development 为开发资料；confirmation 的培训签到和物资配送在开发期间没有建立索引或提供给模型。

表格结构来源：

- 上海理工大学出版学院，[低值易耗品表格](https://ccad.usst.edu.cn/2024/1217/c6911a331983/page.htm)，2026年10月30日读取。
- 南京审计大学金审学院，[公开采购资料](https://www.naujsc.edu.cn/2026/0909/c54a24696/page.htm)，2026年10月30日读取。

同一采购资料中的原生Word需求文档用于独立的一项阅读交付测试。原文没有随源码或应用分发。需要重放该项时，先运行 `python scripts/prepare_public_office_v26.py --restore-public-document`，脚本只下载固定公开URL并核对冻结SHA256；来源变化时拒绝替换。它不会访问应用工作区或个人记录。其余12项不需要这个原文。

表格使用随Codex提供的artifact-tool导入、填入虚构数据和导出，全部工作表均渲染检查。预期值由单独读取已保存文件、使用Decimal和日历计算得到。以上属于开发者组织的验证，不是独立用户研究，也不是未知工作簿的总体成功率。

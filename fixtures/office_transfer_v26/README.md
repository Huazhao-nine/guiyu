# 额外迁移资料

支持日志与共享工位文字均为虚构资料。它们在主测试的输出列／Word指令边界问题修正后新建，文件与独立预期在模型首次运行前冻结。新增工作簿使用artifact-tool创建，两张工作表均渲染查看；预期通过单独读取保存后的工作簿、Decimal和日历计算得到。

支持日志包含不同表头位置与列顺序、分钟／小时和元／千元、先保留原始首次记录、日期开闭边界与嵌套条件。短追问检验是否保留原分组与排序。文字任务包含新通知改价和改期、可退押金不计入费用，以及未付款状态。

最初冻结记录为 `qa/v0.26/transfer-freeze.json`。首次模型执行前又完成了追问范围与排位选择的静态审阅，执行用后端哈希单独记在 `qa/v0.26/transfer-protocol.json`；输入、目标、预期没有改动。该组首次2/3，支持日志和排位追问通过；文字任务没有正确协调最新单价与日期，核对未完成后停止交付。后续已知任务成绩不能替代这个首次结果。

这是开发者组织的额外检查，能够帮助发现机制问题，不能代表独立用户或任意资料的成功率。
